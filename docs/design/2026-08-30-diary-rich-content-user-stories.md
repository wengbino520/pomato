## 1. 用户故事列表

### US-01: 直接粘贴表格
> 优先级: P0

**作为** 日记使用者，  
**我希望** 能直接把 Excel / 网页表格粘贴到日记里，  
**以便** 记录结构化信息，不再手工重写。

**验收标准**：
- [ ] Given 用户在日记编辑区复制了表格内容，When 执行粘贴，Then 表格行列结构保留并可见
- [ ] Given 表格已粘贴，When 保存并重新打开日记，Then 表格仍然存在且排版稳定
- [ ] Given 只有纯文本内容，When 粘贴，Then 系统不破坏原有正文格式

---

### US-02: 粘贴图片与截图
> 优先级: P0

**作为** 工作复盘用户，  
**我希望** 能直接粘贴截图或图片到日记中，  
**以便** 保存证据、界面状态和视觉内容。

**验收标准**：
- [ ] Given 用户复制了图片到剪贴板，When 粘贴到日记，Then 图片被插入到编辑区并可见
- [ ] Given 用户拖拽本地图片文件到编辑区，When 释放文件，Then 图片成功插入并保存
- [ ] Given 图片已插入，When 保存后重新打开，Then 图片仍可正常显示

---

### US-03: 历史回看保留富内容
> 优先级: P0

**作为** 日记长期使用者，  
**我希望** 历史日记能够按原始内容显示图片和表格，  
**以便** 复盘时看到完整记录，而不是只有纯文本摘要。

**验收标准**：
- [ ] Given 某天日记包含图片或表格，When 打开历史日记，Then 富内容能够正确还原显示
- [ ] Given 当前日记没有富内容，When 打开历史，Then 系统退回普通文本展示，不报错
- [ ] Given 图片文件缺失，When 打开历史，Then 系统显示占位提示并保留日志信息

---

### US-04: 兼容旧日记数据
> 优先级: P0

**作为** 现有用户，  
**我希望** 现有纯文本日记保持可读、可编辑和可保存，  
**以便** 不因增强功能导致数据丢失或兼容性问题。

**验收标准**：
- [ ] Given 旧版本日记只有纯文本，When 打开该日记，Then 内容仍然可显示和编辑
- [ ] Given 用户保存旧文本日记，When 退出后再次打开，Then 文本内容不被破坏
- [ ] Given 新增富内容字段为空，When 读取数据，Then 系统自动回退到传统文本字段

---

### US-05: 低门槛输入体验
> 优先级: P1

**作为** 日常使用者，  
**我希望** 能直接从其他应用复制内容粘贴到日记里，  
**以便** 不需要手工转换格式，减少输入成本。

**验收标准**：
- [ ] Given 用户从 Word 或网页复制了富文本，When 粘贴到编辑器，Then 内容能保留基本结构
- [ ] Given 用户复制了纯文本，When 粘贴，Then 内容按普通文本处理，不丢失
- [ ] Given 粘贴内容包含多种格式，When 保存，Then 系统以安全白名单方式处理并保留可展示内容

---

### US-06: 本地化存储与资料空间隔离
> 优先级: P1

**作为** 数据安全优先型用户，  
**我希望** 图片和附件保存在当前资料空间的本地目录中，  
**以便** 数据仍然属于本地、隔离且不污染其他资料空间。

**验收标准**：
- [ ] Given 用户在某个资料空间中保存图片，When 读取该资料空间日记，Then 图片从该空间目录读取
- [ ] Given 切换到不同资料空间，When 查看日记，Then 仅显示当前资料空间对应附件
- [ ] Given 图片删除后，When 打开日记，Then 相关引用不产生崩溃或空白展示
